你有沒有曾經想過 JavaScript 拿到一串程式碼時，他到底做了什麼。

趕時間的人可以直接跳到後面的總結，如果你想聽聽一個小Ｊ的故事，可以讓我們一起發揮一下想像力。

## 小 J 的故事

有一位做事認真辦事負責的好員工 — 小 J，他是公司的超級小幫手，主要的工作就是執行所有同事需要交辦的任務。小 J 做事很有規劃，每天的工作就是先看好今天有什麼任務清單，老闆還會告訴他今天在哪裡有哪位需要接待的貴賓（但每次都不會告訴他名字），仔細地清點登記完他今天工作時的所需，才會開始工作。

因為他的工作就是執行老闆、同事交派的任務，如果沒人呼叫他，他就可以直接打混摸魚到下班，但通常是沒這麼好的事啦～正在發呆想下班時，小 J 才收到原來今天要接待的貴賓叫老陳啊，老闆今天要跟老陳開會，所以請他去某某酒店接他，但跑到飯店的小 J 居然沒看到老陳，但好險，做事細心的小 J 早就在今天工作前，取得了這位貴賓可能會出現的地方，只要沿線找肯定找得到，如柯南般的小 J 當然順利依照事前準備找到老陳了。

回辦公室的小 J 還沒休息喘口氣就聽到Ａ同事說「小 J 啊～剛剛你已經看過工作清單了吧，我需要的 A 任務你可以開始執行囉！」小 J 這時就會按照 A 同事要求先認真地清點需要的工作清單，清點完畢後再依照的工作流程認真執行任務。突然此時工作到一半，Ｂ同事跑過來「小 J 啊～我的文件呢？我不管，這份 PPT 你要先做！」聽話的小 J 只好放下手邊的工作馬上處理 B 同事的 PPT 。

認真的小 J 做事真的需要極度專心，你要他邊做 PPT 邊做 A 同事的任務是不可能的，因為他一次就只能做好一件事而已，但請放心他只要把工作做完，就會回頭繼續完成 A 同事交辦的任務了，小 J 真的是一位又老實又可靠的好員工呀。

看完這個很有奴性小 J 的故事，我們就可以進入正題談談 JavaScript 的運作規則了，我們來看看這個 J 是不是就是那個 J。

## 執行環境與堆疊

JavaScript 底層要開始執行的時候，第一步會先建立一個**執行環境（Execution Context）**，而每個執行環境都會配有一個自己的執行環境物件。

建立執行環境時，又會分為 2 階段：

1. **Creation Phase 創造階段**（小Ｊ先看好需要的工作清單，這跟之後講的提升有很大的關係喔）
2. **Execution Phase 執行階段**（開始工作！）

### 創造階段

在創造階段到底是在創造什麼呢？他其實是在記錄下所有執行階段時所需要用的物件，分別有：

- 全域底下 `window` 有什麼
- 變數物件（Variable Object）
- 作用域鏈（Scope Chain）
- `this` 變數（"This" Variable）

### 執行階段

第一個默認的執行環境就是**全域執行環境（Global Execution Context）**，當全域執行環境創造完，進入執行階段後，一行一行往下跑著，這時呼叫 A 函式時，這個全域執行環境就會為 A 函式建立一個 A 函式執行環境 `Execution Context functionA`，再進入 A 函式中逐行執行。（Ａ同事呼叫小Ｊ工作了）

若在 A 函式中又呼叫另一個 B 函式，就會再建立新的 B 函式執行環境 `Execution Context functionB`，並堆疊在 A 函式執行環境的上方。（Ｂ同事要小Ｊ先去處理文件）如果不斷地在函式中呼叫另一個函式，所有執行環境就會不斷往上堆疊，這些堆疊在一起的執行環境稱為**執行堆疊（Execution Stack）**。

因為 JavaScript 為**單線程（single-threaded）、同步語言**：簡單來說，就是「一次只能做一件事。」

他優先會處理最頂端的執行環境，也就是正在執行中的環境，稱為**現行環境（Active context）**。

而等到函式執行完成並且 Return 之後，即會消失。

## 小結

| 概念                          | 說明                                                        |
| ----------------------------- | ----------------------------------------------------------- |
| 執行環境（Execution Context） | JavaScript 執行時建立的運作環境，包含變數、作用域鏈、`this` |
| 創造階段（Creation Phase）    | 執行前先掃描並記錄變數、函式等資訊                          |
| 執行階段（Execution Phase）   | 逐行執行程式碼                                              |
| 執行堆疊（Execution Stack）   | 多個執行環境堆疊在一起，後進先出（LIFO）                    |
| 單線程（Single-threaded）     | 一次只能執行一件事                                          |
| 現行環境（Active context）    | 目前堆疊最頂端正在執行的環境                                |
